#### License types

DBeaver | CloudBeaver | Team Edition

There are various license types available for the DBeaver products.  
All of them are distributed per named users, not concurrent users. You can find a short description of each license type below.

# DBeaver

###### DBeaver Trial license

The DBeaver Trial license is a free individual license that provides full access to DBeaver Lite, Enterprise, or Ultimate editions for 14 days. After that, access to DBeaver will be blocked. The user will not have access to the product and technical support.

You can request the Trial license from the DBeaver application directly or by filling the [special form](/trial/) on the site.

You can request the trial license for each new version of DBeaver products, but only once.

###### DBeaver Early Access Program License

The Early Access program license allows users to test the pre-release versions of the DBeaver Lite, Enterprise, or Ultimate Edition for free. The Early Access Program involves using the early access build, not the stable release version.

The users can join the Early Access Program in the application once the trial license expires. After that, a special license key will be issued which can be used only for the Early Access product version.

The program’s duration of participation is unlimited as long as the user follows all the restrictions. DBeaver has the right to terminate or unilaterally change the program at any time.

Participating in the Early Access Program is voluntary; however, it obligates the user’s consent to collect statistics on the DBeaver products’ use.

The Early Access Program has a set of restrictions:

  * 3 database connections: the user can have only three simultaneous database connections. If the user has set up more than three connections, the application won’t work until the extra connections are removed.
  * 5 automation tasks: the user can create and run only five simultaneous tasks. In case of composite tasks, the composite task itself or its components are considered.
  * No CLI for CI/CD: DBeaver under EAP can’t be run through the command line.
  * No task scheduler: Task Scheduler is not available.
  * Only one default workspace: The user can run DBeaver with a single default workspace only. The application won’t work with any other workspace.
  * Only one default project: The user can run DBeaver with a single default project only. The application won’t work with any other project.



Each Early Access product version works for one month after the build creation date. After that, the user will have to download a new product build version on the DBeaver website.

To cancel participation in the Early Access program user may delete application from their workstation or buy and import a subscription license key into the DBeaver License Manager. Using the regular subscription license key will automatically remove all restrictions.

###### DBeaver Individual Monthly Subscription

The Individual Monthly Subscription provides full access to DBeaver Lite or Enterprise Editions, and also gives access to new product versions and a technical support system during the subscription period.

This subscription is **for individual users only.** The license cannot be shared or reassigned from one user to another.

One user can install DBeaver with this license **on a few workstations if they are used by this user only.**

The Monthly Subscription**requires internet access** on the workstation **for the first** activation and each prolongation. The user will not be able to use DBeaver products with the monthly subscription without activation.

By default, the subscription is automatically renewed every month. You can stop auto-prolongation at any time in your personal account or in the [FastSpring storefront](https://dbeaver.onfastspring.com/account). The license will have been valid until the end of the current subscription period but you will not be charged next month. After that, access to DBeaver will be blocked. The user will not have access to the product, technical support, or product updates. You can remove the cancellation prior to the next rebill period to keep the subscription. If you don’t remove the cancellation, the subscription expires. Then you cannot un-cancel a deactivated subscription, but you can purchase a new one.

If you want to stop an active subscription for a while, you can pause it for 1 – 10 months. In this case, you will not be charged during the selected period of time and will not be able to use the product. The subscription will be automatically resumed at the end of the selected period. You can resume the paused subscription in your personal account at any time during the selected period.

###### DBeaver Individual Yearly Subscription

The Individual Yearly Subscription provides full access to DBeaver Lite, Enterprise or Ultimate Editions, and also gives access to new product versions and a technical support system during the subscription period.

The Individual subscription is distributed per user. One user can install DBeaver with this license **on a few workstations if they are used by this user only**.

This subscription **doesn’t require internet access** on the user’s workstation. With this license, the user can run DBeaver **in offline mode or behind a corporate firewall.**

After the end of the subscription period, access to DBeaver will be blocked. The user will not have access to the product, technical support, or product updates. Before the subscription expires, it is possible to renew it to continue using the product.

###### DBeaver Group Yearly Subscription

The Group Yearly Subscription is **a single subscription license key** created for a determined number of users. It provides full access to DBeaver Lite, Enterprise or Ultimate Editions, and also gives access to new product versions and a technical support system during the subscription period.

The customer can order a group subscription license for any number of users. The group license considers named users, not simultaneous. The number of users can be increased during the active subscription period by [email request](mailto:sales@dbeaver.com). It is possible to reduce the number of users before the next year’s renewal.

DBeaver with the Group subscription license can be installed **on a limited number of workstations according to the number of users in the license.** Each user accessing DBeaver has to be counted in the Group license.

DBeaver with the Group subscription license can also be installed on a virtual machine or a server with limited access for a determined number of users.

This subscription **doesn’t require internet access on the user’s workstation.** With this license, the users can run DBeaver **in offline mode or behind a corporate firewall.**

After the end of the subscription period, access to DBeaver will be blocked. The users will not have access to the product, technical support, or product updates. Before the subscription expires, it is possible to renew it to continue using the product.

###### DBeaver Perpetual license (obsolete)

DBeaver has not provided new perpetual licenses since version 23.3. Customers with existing perpetual licenses for DBeaver Lite, Enterprise or Ultimate Editions can continue using DBeaver software as long as they need it.

The perpetual license extension is available for authorized users with existing perpetual licenses. It provides one year’s access to new product versions and a technical support system.

###### DBeaver Academic license

The DBeaver Academic license provides full access to DBeaver Enterprise Edition and gives access to new product versions for one year. Technical support is not provided to academic users.

The Academic license is free for students and teachers only. It is meant for academic purposes only. Running the software with this license in the corporate environment is not allowed.

If you want to get an Academic license, you need to fill out a [special form](/academic-license/). We use a [university](/clients/universities/) email for your status verification, so please, use your university account for the request. The official request from the university email is the easiest way to receive the Academic license. If you do not have a university email, you have to attach some documents for your status verification, e.g., a photo of your student card, a contract with your name, etc.

All requests are reviewed manually. Usually, it takes about three business days.

The Academic license is valid for one year. It is impossible to extend the existing Academic license. If you want to get the Academic license for an additional year, you will need to request a new license and reaffirm your student or teacher status.

# CloudBeaver

###### CloudBeaver Trial license

The CloudBeaver Trial license is a free license for 5 users that provides full access to CloudBeaver Enterprise Edition for 14 days. After that, access to CloudBeaver will be blocked. The users will not have access to the product and technical support.

You can request the trial license by filling out a [special form](/trial/) on the site.

You can request the trial license for each new version of the CloudBeaver Enterprise, but only once.

###### CloudBeaver Single-Server Yearly Subscription

The Single-Server Yearly Subscription license provides full access to CloudBeaver Enterprise Edition, and also gives access to new product versions and a technical support system during the subscription period.

The license works **for one server and a limited number of the named users**. A customer can order the license for any number of users, but the minimum number is 5.  
The single-server license considers named users, not simultaneous. **Each user accessing CloudBeaver Enterprise server has to be counted in the Single-Server license.** The number of users can be increased during the active subscription period by [email request](mailto:sales@dbeaver.com) or on [our website](https://dbeaver.com/buy/). It is possible to reduce the number of users before the next-year renewal.

CloudBeaver Enterprise can be run anywhere in the users’ infrastructure: on-premise or in any cloud. The license key is imported to the server during installation and updated through the admin panel inside the application.

This subscription **doesn’t require internet access on the server.** An administrator can run CloudBeaver Enterprise with this license **in offline mode or behind a corporate firewall.**

After the end of the subscription period, access to CloudBeaver Enterprise will be blocked. Users will not have access to the service, technical support or product updates. Before the subscription expires, it is possible to renew it to continue using the product.

###### CloudBeaver Multi-Server Yearly Subscription

The Multi-Server Yearly Subscription is a single license key that provides full access to CloudBeaver Enterprise Edition for a limited number of users working on a certain number of independent servers and also gives access to new product versions and a technical support system during the subscription period.

A customer can order the license for any number of users, but the minimum number is 5. The number of users can be increased during the active subscription period by [email request](mailto:sales@dbeaver.com) or on [our website](https://dbeaver.com/buy/). It is possible to reduce the number of users before the next-year renewal. The number of servers can be increased only by [email request](mailto:sales@dbeaver.com). It can also be reduced before the next-year renewal.

CloudBeaver Enterprise can be run anywhere in the users’ infrastructure: on-premise or in any cloud. The license key is imported to the server during installation and updated through the admin panel inside the application.

The important limitation is that all users of the multi-server license key have to be named and counted in the license, even if only a part of them has access to two or more servers.

**[The user management for the multi-server license](https://dbeaver.com/docs/cloudbeaver/Multi-server-license/#setup) is available on dbeaver.com and in the application itself.** The license administrator has to create and keep the user list up to date to provide access to these users. Multi-Server subscription **requires an internet connection on the server to automatically update the users inside the application.** If the server doesn’t have an internet connection, the administrator has **to reimport the license key to the server.**

After the end of the subscription period, access to CloudBeaver Enterprise will be blocked. Users will not have access to the service, technical support or product updates. Before the subscription expires, it is possible to renew it to continue using the product.

###### CloudBeaver AWS license

An AWS-adapted version of CloudBeaver Enterprise is available on the AWS marketplace. You can install the AWS-adapted version of CloudBeaver Enterprise from the AWS marketplace and test it for free for 30 days.

Depending on the environment settings, users can select hourly or annual pricing options. CloudBeaver AMI is cloud-managed and can be brought up and down on demand or as part of the AWS CI/CD process.

The subscription is managed by the AWS marketplace. DBeaver team **does not manage the subscription** and cannot cancel it by request.

###### CloudBeaver Academic license

The Academic license is a free license for students and teachers only. It is meant for academic purposes only. Running the software with this license in the corporate environment is not allowed.

If you want to get an Academic license, you need to fill out a [special form](/academic-license/). We use a university email for your status verification, so please, use your university account for the request. The official request from the university email is the easiest way to receive the Academic license. If you do not have a university email, you have to attach some documents for your status verification, e.g., a photo of your student card, a contract with your name, etc.

All requests are reviewed manually. Usually, it takes about three working days.

The Academic license is valid for one year. It is impossible to extend the existing Academic license. If you want to get the Academic license for an additional year, you will need to request a new license and reaffirm your student or teacher status.

# Team Edition

###### Team Edition Trial license

The Trial license is a free license for one administrator, three developers, three managers, three editors and three viewers for testing the Team Edition for 14 days. After that, access to Team Edition will be blocked. The users will not have access to the product and technical support.

You can request the Trial license by filling the [special form](/trial/) on the site.

You can request the trial license for each new version of the DBeaver Team Edition, but only once.

###### Team Edition Single-Server Yearly Subscription

The Single-Server Yearly Subscription license provides full access to DBeaver Team Edition and also gives access to new product versions and a technical support system during the subscription period.

The license works **for one server and a limited number of users** with different role types: administrator, developer, manager, editor and viewer. A customer can order the license for any number of users, but the minimum number of users is 3 and one of them must be an administrator.

The Team Edition Single-Server license considers named users, not simultaneous. Each user accessing DBeaver Team Edition server has to be counted in the Single-Server license. The number of users can be increased during the active subscription period by [email request](mailto:sales@dbeaver.com) or on [our website](https://dbeaver.com/buy/). It is possible to reduce the number of users before the next-year renewal.

The license key is imported to the server during installation and updated through the admin panel inside the application.

This subscription **doesn’t require internet access on the server.** Administrator can run DBeaver Team Edition server with this license **in offline mode or behind a corporate firewall.**

After the end of the subscription period, access to DBeaver Team Edition will be blocked. Users will not have access to the service, technical support or product updates. Before the subscription expires, it is possible to renew it to continue using the product.

###### Team Edition Multi-Server Yearly Subscription

The Multi-Server Yearly Subscription is a single license key that provides full access to DBeaver Team Edition **for a limited number of users working on a certain number of independent servers** and also gives access to new product versions and a technical support system during the subscription period.

A customer can order the license for any number of users with different role types: administrator, developer, manager, editor and viewer, but the minimum number of users is 3 and one of them must be an administrator.  
The number of users can be increased during the active subscription period by [email request](mailto:sales@dbeaver.com) or on [our website](https://dbeaver.com/buy/). It is possible to reduce the number of users before the next-year renewal.  
The number of servers can be increased only by email request. It can also be reduced before the next-year renewal.

The license key is imported to the server during installation and updated through the admin panel inside the application.

**The important limitation is that all users of the multi-server license key have to be named and counted in the license, even if only a part of them has access to two or more servers.**

**[The user management for the multi-server license](https://dbeaver.com/docs/team-edition/web/Multi-server-license/#setup) is available on dbeaver.com and in the application itself.** The license administrator has to create and keep the user list up to date to provide access to these users. Multi-Server subscription**requires an internet connection on the server to automatically update the users inside the application.** If the server doesn’t have an internet connection, the administrator has **to reimport the license key to the server.**

After the end of the subscription period, access to DBeaver Team Edition will be blocked. Users will not have access to the service, technical support or product updates. Before the subscription expires, it is possible to renew it to continue using the product.
