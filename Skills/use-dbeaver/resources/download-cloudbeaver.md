## For AWS services

This version of CloudBeaver Enterprise is suitable for working in a corporate AWS environment. Obtain your CloudBeaver AWS license through the AWS marketplace and streamline database management. AWS users within your organization will gain access to established database connections in CloudBeaver with easy permission management.

You can acquire a CloudBeaver Amazon license and deploy the AWS-adapted version of CloudBeaver Enterprise directly from the AWS marketplace as an EC2 instance.
