# Welcome to DBeaver Team Edition Documentation¶

![](images/team-edition-head.png)

This is the documentation for [DBeaver Team Edition](https://dbeaver.com/dbeaver-team-edition/), a collaborative database management tool designed for teams and enterprises. It combines the full functionality of DBeaver Ultimate and CloudBeaver Enterprise, offering both desktop and web access for a seamless experience. Built for teamwork, it simplifies workflows and centralizes resource management, making collaboration easy in multi-user environments.

Web ClientDesktop Client

The **Team Edition web client** provides a modern, browser-based interface for collaborative database management. It supports centralized user management, role-based access control, and integration with cloud-hosted databases, making it ideal for team-oriented workflows.

[Learn more](Team-Edition/#web-client-features)

The **Team Edition desktop client** offers a feature-rich interface for database management, including advanced query development, data visualization, and administrative tasks. It provides the flexibility to work locally while supporting team collaboration through shared resources and centralized control.

[Learn more](Team-Edition/#desktop-client-features)
