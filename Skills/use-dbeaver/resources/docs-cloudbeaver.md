# Welcome to CloudBeaver Documentation¶

![](images/cloudbeaver-head.png)

This is the documentation for [CloudBeaver](https://dbeaver.com/cloudbeaver-enterprise/), a powerful database management tool designed for teams and businesses. It supports a wide range of databases, including SQL, NoSQL, and cloud databases, all accessible through a web browser. Optimized for teamwork, it simplifies database operations and allows multiple users to collaborate seamlessly in a cloud-based environment.

CloudBeaver comes in two editions, each tailored to different users and workflows. Find the one that best fits your workflow.

CloudBeaver EnterpriseCloudBeaver AWS

**CloudBeaver Enterprise** , designed for organizations requiring robust database management capabilities. It supports a wide range of relational and NoSQL databases, provides enhanced security features, and facilitates team collaboration with centralized access management. 

[Learn more](CloudBeaver-Enterprise/)

**CloudBeaver AWS** is a web-based database management tool optimized for Amazon Web Services. It enables teams to collaboratively manage AWS-hosted databases through a user-friendly interface, offering features like Cloud Explorer for seamless integration with AWS services. 

[Learn more](AWS-Overview/)
