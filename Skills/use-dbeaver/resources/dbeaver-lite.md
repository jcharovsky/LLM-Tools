### Get the features you need   
without the overhead

Write SQL, connect to multiple databases, visualize data, and export results, all in a compact, easy-to-use app. Access 100+ supported databases including major cloud platforms (AWS, GCP, Azure).

protected

Protect your data with support for modern security standards. Key features include SSO authentication, SSL, SSH tunneling, Kerberos authentication, and encrypted credential storage with Secret Manager integration.
